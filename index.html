Without the localhost companion, export a script and review it line by line. It only creates placeholder commits in the current directory and contains no network request, token, repository initialization, or git push. First create and clone a new, separate practice repository that you own.

  • The script stops outside a Git repository or when the working tree is dirty
  • Keep the script outside the repository and run it with the practice repository as the terminal’s current directory
